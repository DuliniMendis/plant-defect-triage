# Plant Defect Triage

A concept for Gearbelt.

> **Disclaimer.** This is an independent concept demo built for a job interview. It is not a Sitemate product and is not affiliated with, endorsed by or sponsored by Sitemate. Sitemate, Dashpivot, Gearbelt, Flowsite and Storm are names of Sitemate's products and are used here only to describe the idea. The app was built from publicly available information, contains no Sitemate code, data or brand assets, and uses fictional asset data. Not for commercial use.

A mechanic or operator reports a defect on a piece of plant with photos and a voice note. AI drafts the issue, rates its severity, checks the asset's history for repeats and proposes a work order. A person reviews and approves before anything is saved.

See [NOTICE.md](NOTICE.md) for what this repository does and does not contain.

## Stack

Next.js 16 (App Router, Cache Components), TypeScript, Tailwind 4, Vercel AI SDK through Vercel AI Gateway, Neon Postgres with Drizzle ORM, Vercel Blob. Chrome on desktop and tablet.

## Project layout

```
app/                  Pages and API routes; route-only components in each route's _components/
components/           Components shared by more than one route
db/schema.ts          Database tables
db/client.ts          Database connection (server only)
db/migrations/        Generated by drizzle-kit
lib/schema.ts         Zod schema for the triage draft
demo-files/photos/    Sample defect photos and their credits
docs/                 Requirements, plans, usage log
e2e/                  Playwright end-to-end tests
```

## Getting started

Requires Node 22 or later and pnpm.

```bash
pnpm install
```

Link the Vercel project and pull its environment variables (database, Blob, AI Gateway). See `.env.example` for the variables used.

```bash
vercel link
```

```bash
vercel env pull .env.local
```

Create the tables, then start the dev server:

```bash
pnpm db:migrate
```

```bash
pnpm dev
```

## Scripts

| Script | What it does |
|---|---|
| `pnpm dev` | Start the dev server |
| `pnpm build` | Production build |
| `pnpm lint` | ESLint |
| `pnpm typecheck` | TypeScript check |
| `pnpm test` | Unit and component tests (Vitest, React Testing Library) |
| `pnpm test:watch` | The same, re-running on changes |
| `pnpm test:e2e` | End-to-end tests (Playwright, Chromium). First run: `pnpm exec playwright install chromium` |
| `pnpm db:generate` | Generate a migration from `db/schema.ts` |
| `pnpm db:migrate` | Apply migrations to the database |
| `pnpm db:studio` | Browse the database |
